Volatility Surface

A volatility surface shows implied volatility across option expiry and moneyness. Moneyness is strike divided by spot. The surface below is built from the option-chain input file NVDA_surface.csv, which is created by the Python data pull and then used by Volatility_Surface.xlsm for the Excel surface calculations.

NVDA Implied Volatility Surface

The chart plots implied volatility against tenor in years and moneyness, where moneyness equals strike divided by spot. For readability, the displayed image uses call options and filters out very short-dated, very far out-of-the-money, and obviously distorted implied-volatility points. The CSV remains the source data for the full surface calculation.
